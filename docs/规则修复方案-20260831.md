## 二、修复项（3 个实现 + 1 个吸收）

### FIX-1：no-entry 识别 exports 入口
- 现状：只认 `main` 与候选文件名（index.js/lib/*.js），`exports["."]`（string 或 {default}）未识别 → empty-fort-strategy（exports → preset/index.mjs）误报 red。
- 修法：入口解析 `resolveEntry(pkg)` = `main` || `exports["."]`（string 或 default 分支）|| `exports["./client"]`（client 名册入口，dsh.client 声明时）。
- 用例：empty-fort（exports string）、标准插件（main + exports 对象）、client-only（exports["./client"]）。

### FIX-2：workspace 根豁免
- 现状：`private: true` + packages/ 子目录的 monorepo 根被判 no-entry red（skin-pack、sshworkspaces）。
- 修法：`isWorkspaceRoot(pkg, dir)` = private === true 且（`workspaces` 字段存在 或 存在 packages/ 子目录）→ 跳过 no-entry/no-bundle/unbuilt-entry，追加 info finding "monorepo workspace root（审计子包）"。
- 用例：skin-pack、sshworkspaces 形态。

### FIX-3：unbuilt-entry 区分 git/npm 源（remote 审计）
- 现状：--remote 用 git clone，git 源无构建产物 → unbuilt-entry red；但 npm 发布包可能已构建（filesnap：npm 0.2.1 含 lib/index.js，git 源没有）→ 误报。
- 修法：remote 审计发现 unbuilt-entry 时，查 npm registry（同名包 latest）→ 下载 tarball → 检查 main/exports 目标文件是否存在：
  - npm 包含该文件 → 降为 yellow，evidence 注明"git 源未含构建产物（npm 包 vX 已构建）"
  - npm 无包 / tarball 也缺 → 保持 red
  - 网络失败 → 静默保持原判（不因审计通道失败改变结论）
- 实现：`auditRemote` 增加可注入 `npmArtifactCheckFn`（测试注入 fake，生产用真实 fetch+tar，超时 30s 静默降级，与 osv.js 同模式）。
- 用例：filesnap（npm 含 main → yellow）、discord（npm 无包 → 保持 red）。

### FIX-4：client 插件 no-bundle 语义（吸收进 FIX-1/FIX-3）
- 官方机制：client 插件经 exports["./client"] 名册扫描激活，host 面才需 bundle.patch。
- 修法：no-bundle 规则对 `dsh.client` 声明插件：若 exports["./client"] 目标文件存在 → 不判 no-bundle（client 激活路径成立）；若不存在 → 保持 yellow（构建缺失，实际未激活——由 FIX-3 的产物检查兜底）。

## 三、TDD 计划（seam 约定）

- seam 1：`scanner.js` 新增纯函数 `resolveEntry(pkg)`、`isWorkspaceRoot(pkg, dir)`；`auditPlugin` 内调用（现有公共 seam 不变）。
- seam 2：`remote.js` `auditRemote` 新增可注入 `npmArtifactCheckFn`（模式同 dynamicCheckFn）。
- 测试文件：scanner.test.js 加 4 用例（exports 入口 / workspace 根 / client no-bundle / unbuilt 产物检查），remote.test.js 加 2 用例（npm 含 main 降级 / npm 无包保持）。
- 循环：每用例 红 → 最小实现 → 绿；最后全量 78+ 测试回归 + 13 插件复测（empty-fort/skin-pack/sshworkspaces/filesnap 应转 yellow/green）。

## 四、风险与边界

- exports 解析复杂度：仅支持 string 与 {default: string} 一层条件对象（官方文档确认 types 不参与运行时解析）——不实现完整条件导出。
- workspace 根豁免以 `private` 为必要条件，防止误豁免真实插件（private 但单包——无 packages/ 时仍审计）。
- FIX-3 下载 tarball 增加远程审计耗时（仅命中 unbuilt-entry 时触发）；失败静默不改变结论。
